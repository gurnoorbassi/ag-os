# Opportunity Director runtime state

This directory contains source-controlled V1 identity and zero-capital treasury defaults plus runtime-generated, provenance-preserving Opportunity Director records.

The runtime may add evidence, signals, ResearchRuns, opportunities, experiments, outcomes, tactical-rule candidates, decisions, wake records, briefs, and Mission Control links beneath this directory. It may not store credentials, copied webpages, private/customer data, model traces, live outreach, publishing, or real-money execution records.

The Constitution is code-owned in `scripts/lib/runtime/opportunity-constitution.mjs`. Tactical rules remain advisory and require the existing Memory OS promotion process before they can influence global AG OS memory.
